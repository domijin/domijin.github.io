baby-AI: Receipt-Verified Edge Household Agent Architecture

By Domi Jin (Dongming Jin) · May 2026

An open-specs, bounty-style project for an edge-deployed, verbally-trainable household agent. Five subsystems, one charter, every claim backed by a signed receipt.

What this is

baby-AI builds toward a small AI that learns about your household by being talked to, runs on hardware that costs less than a phone, and gets better without ever shipping your data off-device for training.

The work is split across five specs. Each one carries a falsifiable hypothesis and a numeric metric on a named benchmark — see specs/. Code is the means. Signed receipts in receipts/ are the goal.

Hardware target

The compute floor is intentionally cheap so contributors don't need a lab:

  • Yi Dome 1080p (Hi3518EV200, ARMv5, ~ USD 30 used) — frame source only.
  • Raspberry Pi 5 16 GB — stream router, audio, memory, dialogue.
  • Hailo-8L M.2 (13 TOPS, ~ USD 70) — VLM + embedding inference.
  • ReSpeaker 4-Mic Array — audio capture + direction-of-arrival.

Off-device GPU (RTX 4070-class) is used only for periodic adapter training. The full envelope and tier IDs live in specs/00-charter.md.

SOTA anchors

Each spec cites its load-bearing references; the project as a whole stands on top of these (circa 2025–2026):

SmolVLM2 / Moondream2 / PaliGemma 2 (small open VLMs) · SigLIP-2 (image–text encoder) · V-JEPA 2 (predictive video reps, alt backbone) · Distil-Whisper / Whisper.cpp · DPO and KTO (preference tuning) · LoRA / QLoRA · mem0 / Letta (memory frameworks).

Original 2018 brain-dump (motion-flag + MobileNet + static KG + hand-wavy "verbal RL") is preserved in git history; see commits before claude/design-specs-evaluation-UUNNc.

For humans

Repo state today: this is the specs and contract, not the code. There is no working subsystem implementation yet — that's the work being distributed. The one piece of operational tooling that exists is the cron script that pulls recordings from a Yi Dome to a Pi; it lives in CLAUDE.md so it's not lost.

To pledge a bounty against a specific spec / tier, see CONTRIBUTING.md § Bounty mechanism.

To propose a new spec (e.g. a V-JEPA-2 alternative to spec 01), open a feature proposal.
