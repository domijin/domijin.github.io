# Life Hack: iMessage as a Low-Bandwidth Router to the Internet

*Chapter III · Human Agency, Older People’s Independence and Lifelong Play — By Domi Jin (April 2026)*

## Overview

A tiny HCI harness for agent interfaces: use the ordinary iMessage channel to query an internet-connected agent when normal browsing is expensive, blocked, or unavailable (such as in-flight messaging tiers or satellite text channels).

### Core Mechanisms

- **Plane Mode Internet**: On many flights, messaging works without full Wi-Fi. The agent turns that narrow channel into web search, synthesis, and practical answers.
- **Satellite-Text Edge Cases**: When cellular data is unavailable but satellite text survives, short prompts route to an internet-connected machine.
- **Constrained I/O Compression**: Accepts brief, informal messages and returns high-density answers tailored to messaging constraints.
- **Human-Centered Harness**: Treats messaging as an asynchronous, interruptible, low-attention control surface for agents.
